# Changelog

All notable changes to the Delta Green Enhanced Combat HUD module will be documented in this file.

## [1.0.0] - 2026-08-11
### Added
- Initial release of Delta Green Enhanced Combat HUD.
- Agent vitals panel (HP, WP, SAN, Breaking Point, Armor).
- Equipped weapon sets and rapid attack/lethality/damage rolls.
- Categorized Delta Green combat skill grid and percentile roll engine.
- Sanity loss, adaptation, and Willpower point boost controls.
- Canvas target selection overlay with keyboard shortcuts (`Shift+A`, `T`, `+`, `-`).
- Foundry Combat Tracker turn and movement tracking integration.
- Release automation workflow and esbuild release builder.
